import { Card, CardGrid } from '@astrojs/starlight/components';

:::note[Status]
Croft is experimental and runs in a lab cluster, not in production. The comparison of `croft scale` with the HPA is still running, so this project does not yet claim an improvement.
:::

<CardGrid>
	<Card title="Sees requests before CPU" icon="rocket">
		A web server makes a steady number of syscalls per request, measured for each application. Their rate is the request rate, seen from inside the node, polled every 2 s.
	</Card>
	<Card title="eBPF, /proc and cgroups" icon="puzzle">
		eBPF for events no file keeps: syscalls, waits for a CPU, calls into the GPU driver. Files for the counters the kernel already keeps.
	</Card>
	<Card title="Knows what a task runs" icon="list-format">
		Framework from the libraries a process loaded: PyTorch, TensorFlow, JAX, vLLM, Ray, Spark and more, from a JSON catalog.
	</Card>
	<Card title="A dataset per node" icon="document">
		One JSON line per process per poll, rotated hourly into zstd segments, joined to experiments by container id.
	</Card>
</CardGrid>

![croft architecture: inside the Linux kernel, eBPF programs and kernel files record syscall rates, bytes moved, CPU wait, connections, socket I/O, GPU use, CPU pressure and processes for your app's pods. The croft collector reads them every 2 seconds and writes a dataset, serves Prometheus and feeds croft scale, which sets the number of pods.](../../../../assets/architecture.svg)
